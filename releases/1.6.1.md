## What's new since 1.6.0

- The inspector shows who signed an app, such as **Developer ID Application: Superlogical, Inc. (AG92C3PT77)**, the certificate `codesign` lists first as its Authority. The command-line tool prints it as **Signed By** (`signer` in `--json`), and exported JSON and CSV include it.
- Calmer colors: app tags are neutral capsules with a colored dot, sidebar icons are gray, and only the active filters are highlighted instead of every section's **All** row.
- Evidence lists an item once per trait when several rules match it, such as Rust's two code strings in one binary, with every matched rule in its tooltip.
- The update prompt shows these release notes instead of linking to the GitHub release page.
- Cached results are re-detected on first launch.
